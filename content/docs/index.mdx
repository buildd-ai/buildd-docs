# Welcome to Buildd

Buildd coordinates AI coding agents. You set a goal, agents break it into tasks,
your runners do the work, and you get PRs, artifacts and research back.

- Create missions and tasks from the dashboard, chat, the API or MCP
- Runners you control claim tasks and run Claude Code or Codex
- Watch progress live, and decide what merges with a merge policy
- Agents share a built-in team memory through `recall` and `learn`

## Pricing

Buildd is free while in beta. You bring your own model key: Anthropic,
OpenRouter or your LiteLLM gateway, plus OpenAI for Codex tasks. A runner that
buildd hosts for you is coming soon at $20/month.

## Get started

```bash
curl -fsSL https://buildd.dev/install.sh | bash
buildd login
buildd
```

See [Runner Setup](/docs/getting-started/runner) for what each step does.
